# Toza — мобильное приложение (PWA)

Устанавливается на телефон как обычное приложение: своя иконка, запуск без браузера, работает офлайн.

## Запуск на GitHub Pages
1. Создайте репозиторий на GitHub.
2. Перетащите ВСЕ файлы из архива (index.html, manifest.webmanifest, sw.js, иконки) в репозиторий и нажмите Commit.
3. Settings → Pages → Branch: main, папка / (root) → Save.
4. Откройте ссылку https://ВАШ-ЛОГИН.github.io/ИМЯ-РЕПОЗИТОРИЯ/ на телефоне.

## Установка на телефон
- Android (Chrome): вкладка «Профиль» → «Установить» или меню браузера → «Установить приложение».
- iPhone (Safari): «Поделиться» → «На экран Домой».

## Что поменять (блок НАСТРОЙКИ в начале скрипта в index.html)
- tg — username вашего Telegram без @ (туда приходят заказы)
- phone — телефон для кнопки «Позвонить»
- min, promo — минимальный чек и промокоды
- OBJ, TYPES, EXTRA, DIST, TIMES — объекты, цены за м², допуслуги, районы, время
- Название «Toza» — в index.html и manifest.webmanifest

## Обновления
Приложение сначала берёт свежие файлы из сети, поэтому после загрузки новой версии на GitHub оно обновится само.

## Google Play
Для магазина приложений вставьте ссылку на ваш сайт на pwabuilder.com и скачайте Android-пакет.
